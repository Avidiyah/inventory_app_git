Import / Export

Work orders come from the CSV export — upload the latest one. Existing numbers are updated in place, so nothing is duplicated and edits made here survive a re-import. Export writes one row per work order, leading with the same columns the import reads, so a downloaded file can be uploaded back. For Client writes the billing sheet instead: work order number, material and labor totals, and the full receipt.

Work Orders

Work orders start Created, become Assigned when one or more technicians are selected, and move to In-Progress when material or labor is added or an in-scope user clicks Set In-Progress. Technicians and supervisors can mark work completed; supervisors confirm when it is ready for Review. Supervisors can roll back status or place work On-Hold in Edit details. Every expanded card has free-form Notes and labor tracking billed in rounded-up 30-minute increments. Closed work orders are handled from Admin Review.
